# Getting help

- **Setup questions and "how do I"**: ask in [Discussions, Q&A](https://github.com/westidwell/sofa-chat/discussions/categories/q-a).
- **Something is broken**: [open a bug report](https://github.com/westidwell/sofa-chat/issues/new/choose).
- **An idea**: post it in [Discussions, Ideas](https://github.com/westidwell/sofa-chat/discussions/categories/ideas).
- **You built something with it**: show it off in [Show and tell](https://github.com/westidwell/sofa-chat/discussions/categories/show-and-tell).

Questions about your Anthropic account, API key or bill go to Anthropic, since Sofa Chat never sees them. Never post your API key anywhere, including here.
