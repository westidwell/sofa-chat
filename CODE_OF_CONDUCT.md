# Code of conduct

Sofa Chat is a small, friendly project. Be the kind of person you'd want on the couch next to you.

- Be kind and patient, especially with people who are new to Swift, Xcode or GitHub.
- Disagree about code, not about people.
- No harassment, insults, or sexual or violent content, here or in messages to people you met here.
- Don't share anyone's private information, and never post API keys.

If someone breaks these rules, the maintainer may edit or remove what they posted, or block them from the project. To report a problem privately, use the [private report form](https://github.com/westidwell/sofa-chat/security/advisories/new) or contact the maintainer through their GitHub profile.

This code of conduct takes its spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
