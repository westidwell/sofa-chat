# Contributing

Thanks for helping out.

- **Bugs and ideas:** open an issue. Say what you expected, what happened and which platform you're on.
- **Pull requests:** keep them small and focused, add or update a test, and run `swift test` before you open it. The engine has no dependencies, so please don't add any.
- **Your key:** never paste a real API key in an issue, a test or a log. Tests use a fake key and a fake network.

By contributing, you agree that your work is shared under the MIT License.
